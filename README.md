# GeoClone 🌍
Tựa game đoán vị trí địa lý lấy cảm hứng từ GeoGuessr, xây dựng bằng HTML/CSS/JS thuần, Leaflet.js và Pannellum.

## Tính năng
- Xem toàn cảnh 360° tương tác mượt mà.
- Mini-map tự động phóng to khi rê chuột vào góc dưới.
- Tính khoảng cách thực tế theo công thức Haversine và chấm điểm thang 5000.
- Vẽ đường nối giữa vị trí đoán và vị trí thực tế sau mỗi vòng.

## Cách chạy & Deploy lên GitHub Pages
1. Push toàn bộ file lên repository GitHub.
2. Vào **Settings** -> **Pages**.
3. Ở mục **Branch**, chọn `main` (hoặc `master`) và nhấn **Save**.
